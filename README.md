# 우리 캘린더 (PWA MVP)

위젯 없이, "혼자 모드"로 먼저 동작하는 캘린더 앱이에요.
홈 / 캘린더 / 일정 등록 / 설정 4개 탭으로 구성돼 있어요.

## 파일 구성
- `index.html` — 지금 미리보기로 바로 확인 가능한 버전 (JS가 파일 안에 다 들어있음)
- `app.js` — 실제 배포할 때 쓸 분리된 로직 파일 (index.html에서 `<script src="app.js">`로 불러오도록 바꾸면 됨)
- `manifest.json` — "홈 화면에 추가"를 진짜 앱처럼 보이게 해주는 설정 파일
- `service-worker.js` — 오프라인에서도 앱이 열리게 해주는 파일
- `icon-192.png`, `icon-512.png` — 앱 아이콘 (임시로 만든 거라 나중에 바꿔도 돼요)

## 지금 뭐가 되나요?
- 일정 추가/삭제, 캘린더에서 날짜별로 보기, 홈에서 오늘/다가오는 일정 보기까지 됩니다.
- **새로고침하거나 앱을 껐다 켜도 데이터가 그대로 남아요** (localStorage 적용됨).
- 단, 이 저장은 **"이 폰의 이 브라우저 안"에서만** 유지돼요. 파트너 폰이랑 자동으로 공유되진 않아요 (그건 다음 단계인 Firebase 연동에서 해결할 부분).
- 파트너 초대 버튼은 아직 자리만 잡아뒀어요 (다음 단계에서 연결).

## 무료로 배포해서 내 폰에 설치하는 법 (GitHub Pages)

코딩 몰라도 따라할 수 있는 순서예요.

1. [github.com](https://github.com) 가입 (무료)
2. 새 저장소(Repository) 만들기 — 이름은 아무거나 (예: `couple-calendar`)
3. 이 폴더 안 파일들(`index.html`, `app.js`, `manifest.json`, `service-worker.js`, 아이콘 2개)을
   그 저장소에 그대로 업로드 (저장소 페이지의 "Add file → Upload files" 버튼 사용)
4. 저장소 Settings → Pages 메뉴 → Branch를 `main`으로 설정 → Save
5. 몇 분 기다리면 `https://내아이디.github.io/couple-calendar/` 같은 주소가 생겨요
6. 아이폰 Safari로 그 주소 접속 → 공유 버튼 → "홈 화면에 추가"

이렇게 하면 서버 없이, 한 푼도 안 들이고 진짜 내 폰에 앱처럼 깔려요.
파트너도 똑같이 그 링크로 접속해서 각자 폰에 설치하면 돼요 (지금은 서로 데이터가 공유되진 않아요,
그건 다음 단계인 Firebase 연동에서 해결할 부분이에요).
